# Ручная проверка производительности, 2026-11-24

Сообщение тестировщика: заметных просадок не обнаружено, визуально приемлемо.
Снимок экрана пользовательского теста: FPS около 100, `COLL 0.70 ms`, `PHYS 0.10 ms`, `RENDER 1.70 ms`, 8 пациентов, 31 капсула на момент снимка, 192 удара, 89 отрывов, 3 динамических обломка и 86 запечённых препятствий. Эти числа — **один наблюдаемый срез**, не среднее, не 1% low и не GPU-время.

Нагрузка и значения меняются из-за ампутаций: на скриншоте 31 активная капсула, а не исходные 120.

Нужно собирать CSV с 60-секундными сериями для 8 пациентов *без повреждений*, *с накоплением обломков* и при показе debug-коллайдеров. Отдельно мерить GPU и сохранять данные устройства/браузера.

Предыдущий дефект: физические обломки улетали вверх из-за очень низкой массы, заданной плотностью, и слишком сильного импульса. В v0.4.1 установлена разумная масса и ограничена начальная скорость. По обратной связи пользователя дефект устранён.

## Отдельный микробенчмарк навигации P3, 2026-11-25

После добавления скольжения `ArenaNavigation.move` проведены только CPU-замеры изолированной функции, не сборка клиента. Среда: Node 22, медиана 5 повторов по 200 000 вызовов на одном устройстве. Базовая / новая версия: открытая арена ~10.1 / 10.1 мс; обычный ход возле одной стены ~15.4 / 18.8 мс; серия касательных столкновений ~32.1 / 75.8 мс; для двух стен при таком же синтетическом рисунке ~32.2 / 81.3 мс. Цена касания выросла приблизительно в 2.4–2.5 раза при абсолютной стоимости менее 0.5 мкс/вызов. Контроль целостности: четыре локальных Node-теста прошли, включая 12 000 детерминированных/случайных проб столкновений, без заглубления корней в прямоугольные коллайдеры.

Это микробенчмарк горячего метода, не игровой FPS / 60-секундный профиль / GPU / Rapier; цифры нельзя сравнивать со старым скриншотом. На этапе P6 или при росте числа стен требуется повторная интеграционная оценка; если измеренная стоимость станет значимой, сначала оптимизировать проверку поверхности или кэширование прямоугольников, не отменяя физически корректное скольжение.
