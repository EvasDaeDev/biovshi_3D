# P1 — first adaptive ground locomotion increment

Mobility selects intact legs, then available arm chains (including upper-arm stumps), then connected head/neck, then the three-part torso. With no legs, a 0.65 s procedural transition blends toward a ground pose, translation is gated until the transition ends. The available parts are animated using IK arm strokes, head extension or torso oscillation; phase also gates root translation. Prone capsule endpoints and midpoints are sampled against terrain and the active envelope is vertically corrected. This is a kinematic approximation, not a mass/COM balance solver, physically simulated fall, friction/contact-driven propulsion, exact terrain collision or full independent spine articulation. During transition linear pose blending can temporarily shorten segments. Stump support and body-only movement rates are provisional. Unsupported anatomy stays stationary. One-leg behavior is unchanged.

The browser adds isolated test scenarios for damaged anatomy; selecting one resets the lab, disables fracture and spawns only the player (normal mode retains eight patients and fracture). The tests check posture, floor envelope, motion, mode selection, arm lengths and idle stopping. Browser smoke now also exercises the legless scenario and keyboard locomotion. Performance and visual acceptance are pending.
