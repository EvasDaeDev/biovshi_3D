# Карта исходного репозитория 2D

Файлы проверены в публичном `main` исходного репозитория до разработки пакета.

| Модуль | Функция | Действие для 3D |
| --- | --- | --- |
| `src/game/loop.js` | фиксированный цикл, AI, `robot.tick`, бой, рендер | оставить 2D; сделать отдельный 3D цикл |
| `src/game/state.js` | общий `ctx` | не импортировать напрямую в 3D ядро |
| `src/robot/robot.js` | сборка робота, SVG/DOM, API | выделить модель и рендер |
| `src/robot/body.js` | ID сегментов и граф родителей | переиспользовать через adapter |
| `src/robot/kinematics.js` | 2D IK и атаки | новая 3D IK |
| `src/robot/anatomy.js` | повреждения, разрыв дочерних сегментов, VFX | отделить правила от 2D VFX |
| `src/robot/collision.js` | 2D капсулы и границы | заменить на 3D капсулы |
| `src/systems/combat.js` | план атак, swept контакты, урон | перенести правила; геометрию переписать |
| `src/tower/input.js` | джойстик, координаты SVG | remap на локальные W/S и yaw |
| `src/game/arenas.js` | преобразование JSON локаций | генератор объёмной геометрии |
| `src/render/camera.js` | 2D SVG viewBox | новая HeadCam/SpectatorCam |
| `src/render/robot-skin.js` | 4x4 2D атласы | переходные материалы / GLB |
| `src/betting/*`, `src/ui/*` | финансы, HUD | максимально сохранить через adapter |

Критично: не переписывать проверенный 2D код до тестирования интерфейсов общего игрового домена.
