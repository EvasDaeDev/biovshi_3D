# P3 — port of v1 perception and search

Sources in the repository's local 2D copy: src/config.js vision/light/combat (100° FOV, 300 range, 75 nearby circle, 32 touch, 2.4s memory, ±60° head scan, 20°/s scan, 40°/s track); src/robot/perception.js and src/systems/perception.js (eye and center, target root/eye/center); src/robot/locomotion.js updateHead (bounded local tracking and reflected scan); src/systems/ai.js patrol and last-seen memory (30 samples, 90–290 distance, prefer interior, 3.5–5.5 seconds, clear at 35 arrival or elimination). Convert horizontal distances using existing movement calibration. The native 3D head capsule supplies the eye origin; gaze yaw is an independent logical head orientation and optional debug arrow, not a new articulated head mesh animation. No vertical FOV invented. Near circle and horizontal sector retained. Current convex arena has no internal opaque walls; SightClear adapter supports future geometry but no wall/terrain occlusion is enabled in this scenario. Headless contact sense uses original root distance rule. The new mode evaluates a shared pose snapshot before planning, filters target selection and pincer threats to visible opponents, retains committed strikes without tracking hidden target, and follows only a copied memory point when visibility is lost. No auditory navigation. Preserves existing nearest ranking from the preceding native implementation (v1 leader/attack-source ranking not ported yet). Patrol and head scanning seeded independently. Opt-in arena-vision, existing arena and escape scenarios unchanged. Adds four tests, browser smoke and eight-patient CPU benchmark. Remaining: proper opaque obstacle line-of-sight and routing, head orientation on final models, vision interaction with recoil/physical head strikes, multi-seed natural completion, source ranking and persistent arena. CI pending.

## P3 — восприятие обезоруженного пациента (25.11.2026)

Реакция подвижного пациента без источников удара на вооружённого противника использует тот же `notices` и память `PatientPerception.recalled`, что и обычный тактический выбор. Безголовый пациент замечает угрозу только при близком контакте, а непрозрачная стена перекрывает соответствующие лучи; дальняя невидимая угроза не превращается в всеведущий источник команды. Увиденная угроза обновляет кратковременную память, поэтому после исчезновения из вида пациент может некоторое время продолжать безопасный уход. При отключённом `perceptionCombat` сохранён режим осведомлённости базового автономного боя, как и раньше.

Источник отбора направления — локальная 2D `src/systems/ai.js:fleeAllAttackers`; условия 3D зрения и память — уже существующие в `3d/core/src/combat/perception.ts`, не новый параллельный сенсор. Регрессии в `tests/disarmed.test.mjs`; полный интеграционный CI ещё требуется. Подробности: [P3_DISARMED.md](P3_DISARMED.md).
