# P3 — persistent attention and eight-patient arena

Source: local src/systems/ai.js targetCommitUntil = 1.3 + random() * .7 seconds. Native opt-in tacticalCombat keeps a target during that window within 4 m; selects nearest after expiration, immediately drops eliminated targets. Active strike holds its original living target. A hit by another opponent triggers delayed retaliation (at least .12 s, temperament delay if longer; threat expires after 2.5 s). Repeated hits by the same attacker do not restart notice. Hesitant patients briefly retreat after critical hits (.75 s, 4 s cooldown), only biped, close to the target and not near arena boundaries; backward movement still uses regular gait and recoil. These are provisional 3D behavior values, not imported v1 tactical constants. No false damage, no forced miss, no advanced tactical cover or omniscient pathfinding. Retaliation uses the actual successful damage event. Explicit commands and existing duel modes keep prior selection. Independent seeded RNG does not perturb critical or oil sequences.

createArenaCombatConfig exposes eight free-for-all participants with profiles, all existing attack types, damage, oil, physical handoff and terminal result. Browser arena scenario runs autonomously; HUD shows living count, target IDs and tactical mode in dataset. Tests cover target commitment, retaliation/strike lock, retreat cooldown, deterministic actual damage in group combat and single terminal result. End-to-end natural last-survivor completion across many seeds, navigation/anti-stuck, cover, pincer escape, vision memory and session integration remain open.
