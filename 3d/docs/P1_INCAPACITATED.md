# P1 — terminal physics ownership

LabSimulationCore.incapacitate(id) is an idempotent terminal transition, emits one copied fighter-incapacitated event with the current attached geometry, and stops all self-propelled movement and procedural gait. It keeps fighter identity and segment IDs for later match results. setIncapacitatedPose accepts ordered plain geometry from the physics adapter and validates identity, dimensions and finiteness. Physics-owned actors are fixed obstacles in the kinematic solver, not displaced by its positional correction. Snapshots render the same actor meshes from the external physical pose, with no duplicate procedural body.

Rapier IncapacitatedBodies creates a single dynamic compound rigid body per patient using all surviving capsules and spheres. It preserves the pose at handoff and falls under gravity with a small initial angular perturbation. Corpse-floor, wall, debris, mound and corpse collisions use shared world groups; dead bodies are not converted into terrain cones. Reset frees the common world. This is deliberately NOT an articulated ragdoll: joints remain fixed in the final pose, living patients avoid corpses via capsule correction but do not apply physical impulses to them. The isolated corpse scenario exercises the terminal transition without inventing HP rules. Actual combat incapacitation/oil/trauma triggers belong to P2/P3. Existing living movement unchanged. Tests cover terminal state, physics pose ownership, compound fall, no baking, reset and immovable obstacle response. Browser smoke verifies handoff and reset. Performance and visual acceptance pending.
