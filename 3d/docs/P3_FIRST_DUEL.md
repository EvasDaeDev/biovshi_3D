# P3 — first native 3D duel

Opt-in combatEnabled disables diagnostic contact fracture. Strike phases use v1 config .32/.20/.26 seconds, fixed tick rounding, .90 second start cooldown. One attacking arm with surviving upper/lower segments is selected by reach; target point is locked at windup. The actual shoulder-connected forearm and hand use fixed-length IK. The same pose is rendered and tested against moving victim capsules before collision correction, using bounded adaptive swept sampling of both capsule endpoints (not exact analytic continuous collision). Only thrust can hit, at most one contact per attack. Collect contacts before applying damage, so opposing strikes in a single tick can both land; multiple terminal hits on one victim still follow current damage-state rules. Normal 1 HP only; patient stat critical chance, kicks, head strikes, prone attacks, alternate target choice and advanced AI remain open. Strike starts only upright and outside hit reaction. Simple AI turns toward closest living opponent, approaches, and stops during strike. Explicit commands can request attack with attack:true. A fight with at least two participants ends when <=1 active remains; snapshot exposes winnerId (null draw). No full session/UI integration yet. First duel scenario with automatic two fighters and diagnostic phase/hit/winner, tests for timings, swept contact, lengths, deterministic real hits, no passive damage and winner. Existing benchmark plus eight-fighter combat workload; CI pending. No changes to v1.
