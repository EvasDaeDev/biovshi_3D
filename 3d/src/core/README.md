# Будущее ядро 3D

Здесь пока нет боевого ядра. Не переносить монолит `lab/main.js` сюда одним копированием: сначала добавить тесты на стабильную ориентацию сегмента, контакты и детач, затем разделять обязанности.

Планируемые независимые пакеты: `anatomy`, `rig`, `locomotion`, `collision`, `debris`, `renderer`, `camera`, `input`, `ai`.

Физика живых пациентов не применяется. Сегменты скелета — кинематические части с устойчивой ориентацией, геометрия контакта — капсулы. Динамика Rapier включается только при отделении либо отключении тела.
