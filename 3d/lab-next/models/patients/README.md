# Модели пациентов Lab Next

Активный ресурс: `3d/lab-next/models/patients/dummy02.glb`.
Заменяйте именно этот файл новым GLB, сохраняя идентификаторы и bind-метаданные.
При сборке stage-preview автоматически формирует catalog.json по наличию файла.
Если модели нет или импорт невозможен, игра сохраняет прежнюю геометрию.

## Экспорт Blender

- 17 отдельных анатомических объектов, идентификаторы в custom property segment_id (имена Blender с .001 допустимы); отдельный объект face с UV 0–1 и нормалями наружу.
- GLB, +Y Up, Custom Properties, UV, Normals, без скелета и анимаций. T-pose, метры, исходные оси Z-up/-Y-front, L = -X.
- Сохранить свойства bone_a_blender, bone_b_blender, bone_length_m, radius_m, исходные точки вращения. Геометрию редактировать в Edit Mode; перемещение origin меняет привязку. Точки рук берутся от фактического origin объекта, а длина — из bind-метаданных.
- Не объединять сегменты. face должен быть отдельной поверхностью, не дополнительным физическим сегментом. Случайные текстуры берутся из существующего portraits. Для поверхности face внешний портрет использует начало UV glTF в верхнем левом углу. UV модели берутся из GLB.
- Исходные материалы используются с прежним цветовым различием пациентов; hit tint, cooling, head camera и тени сохраняются.

Загрузчик запекает трансформы в локальные кадры сегментов, переиспользует геометрию и текстуры, создаёт независимые материалы для повреждений. Симуляция и коллайдеры не изменены. Визуальный размер/длинные пальцы могут выходить за капсулу. Редактор поз открывает тот же GLB. Флажок «Исходный GLB» показывает геометрию в координатах экспорта для подгонки скелета и коллайдеров в Т-позе. При выключенном флажке сегменты модели следуют за позой и размерами редактора. Для debris используются существующие quaternion snapshots; точность осевого roll при отделении, особенно head/hand, требует визуальной проверки и не изменена этим патчем.
