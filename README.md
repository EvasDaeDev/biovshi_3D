# ЭКЦЕПРИ 3D — стартовый пакет нового репозитория

**Статус:** подготовка независимого 3D-направления. 3D пока НЕ заменяет 2D-ядро. В комплекте есть проверенный пользователем экспериментальный стенд Collision Lab 04.1, исходный TypeScript-контракт вычислительного ядра, тесты и документация архитектуры миграции.

**Важно:** из среды сборки нельзя было скачать полный GitHub-архив `EvasDaeDev/biovshi` (недоступно разрешение github.com из shell). Поэтому этот ZIP пока **не полный клон исходного репозитория**. В него вложен скрипт, который на компьютере пользователя создаст полноценную копию `main`, перенесёт в неё этот 3D-пакет и не затронет оригинальный репозиторий.

## Сборка полного нового проекта из main

Требуется `git`, `python3`, интернет.

1. Распакуйте ZIP в папку, например `ECCEPRY_3D_STARTER`.
2. Откройте терминал **в этой папке**.
3. Выполните:

```bash
python3 scripts/assemble_project.py --output ../ECCEPRY_3D_PROJECT
```

Скрипт клонирует исходный `main` **без каталога .git**, затем поверх него переносит `3d/` и проектную документацию. В оригинальном GitHub ничего не записывается. Выходной каталог можно инициализировать как новый Git-репозиторий.

Для привязки к конкретному проверенному коммиту:

```bash
python3 scripts/assemble_project.py --ref aa923c6f57b984bce67883707b0291c882a240f3 --output ../ECCEPRY_3D_PROJECT
```

Если исходная игра уже скачана на компьютере, используйте офлайн-вариант:

```bash
python3 scripts/assemble_project.py --source ../biovshi --output ../ECCEPRY_3D_PROJECT
```

## Запуск собранного проекта

```bash
cd ../ECCEPRY_3D_PROJECT
npm ci
npm run dev
```

2D-игра доступна по `/`, стенд — по `/3d/lab/`, общее описание — по `/3d/`.

`npm run build` исходной игры **пока может не включать** дополнительную HTML-страницу `/3d/lab/` в `dist`. Для независимого статического 3D-пакета предусмотрен `python3 scripts/export_3d.py --output ../eccepry_3d_dist`.

## Новая архитектура ядра

- **Действующий стенд:** `3d/lab/` (JavaScript, Three.js, Rapier для обломков). Его код не менялся и он **не использует** новое ядро.
- **Новый типизированный контракт:** `3d/core/src/types.ts` (TypeScript, фиксированный шаг, команды, снимки, события).
- **Эталонная реализация контракта:** `3d/core/src/reference-core.ts` — тестовый пример перемещения корня, **не полноценная симуляция пациентов**.
- **Rust/WASM:** только проектное направление после профилирования; Rust-код в архив пока не включён.

Для проверки новой части (Node.js 22+, интернет только при установке зависимостей):

```bash
cd 3d/core
npm install
npm test
```

Отдельный TypeScript-пакет не меняет зависимости 2D-игры и не требуется для запуска `/3d/lab/`.

## Создание нового GitHub репозитория

В каталоге `ECCEPRY_3D_PROJECT`:

```bash
git init
git add .
git commit -m "Initial ECCEPRY 3D fork from biovshi main with animation lab"
git branch -M main
git remote add origin https://github.com/ВАШ_АККАУН/ВАШ_НОВЫЙ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

Сначала создайте пустой репозиторий GitHub без README/лицензии, чтобы избежать конфликта начальной истории. Перенесённые файлы сохраняют исходные лицензии и авторство; проверьте `CREDITS.md` и права на ассеты прежде чем распространять производную игру.

## Правило безопасности

Изменения в оригинальный `EvasDaeDev/biovshi` не вносились. Пакет не удаляет 2D-движок. Скрипт отказывается перезаписывать существующую выходную папку.
